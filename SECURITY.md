# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/systemtwosecurity/detections-ai-examples/security/advisories/new).
Don't open a public issue or pull request for a vulnerability.

Include the example affected, the steps to reproduce, and the impact you expect. We'll acknowledge the report and keep
you updated while we fix it.

## Scope

This policy covers the code in this repository. For a vulnerability in the detections.ai platform itself, email
[security@detections.ai](mailto:security@detections.ai), as listed in
[security.txt](https://detections.ai/.well-known/security.txt).
